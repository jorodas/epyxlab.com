# 🧪 EpyxLab

**[epyxlab.com](https://epyxlab.com)** — A cloud innovation lab exploring Azure, AI, and modern infrastructure.

## About

EpyxLab is a personal sandbox and portfolio site hosted on GitHub Pages. Named after [Epyx, Inc.](https://en.wikipedia.org/wiki/Epyx), the legendary 1978–1993 video game developer.

## Tech Stack

- Static HTML/CSS (no build step)
- Hosted on [GitHub Pages](https://pages.github.com/)
- Custom domain via GoDaddy DNS

## Setup

1. GitHub Pages enabled on `main` branch
2. Custom domain `epyxlab.com` configured via CNAME file
3. GoDaddy DNS pointed to GitHub Pages IPs
